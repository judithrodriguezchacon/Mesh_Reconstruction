# Mesh Reconstruction

## ROS2
This project uses ROS2 Jazzy.  
Find the ROS2 Jazzy documentation [here](https://docs.ros.org/en/jazzy/index.html).  

## Industrial Reconstruction
Industrial Reconstruction is a utility that creates meshes using an RGB-D Camera.  
Find the Industrial Reconstruction documentation [here](https://github.com/ros-industrial/industrial_reconstruction).  

## RTAB-MAP
RTAB-MAP is a RGB-D, Stereo, and Lidar graph SLAM approach.  
Find the RTAB-MAP documentation [here](https://github.com/introlab/rtabmap).
